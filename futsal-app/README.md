# フットサル ローテーション v4

GK・フィールド・休みを公平に回すローテーション表。データはすべて端末のブラウザ内（localStorage）に保存します。

## 画面

| タブ | 役割 |
| --- | --- |
| 準備 | 今日来る人を選ぶ／遅刻の設定／試合数などの設定／名簿の編集 |
| 試合 | 作戦ボードで今の5人と休みを確認。タイマー、次の交代、2人タップで入れ替え、途中の出入り |
| 全体表 | 全試合の割り当てと出場バランス。共有（LINEなどへテキストで） |
| 記録 | 通算の遅刻ランキング、これまでの開催 |
| その他 | 画面の色、ローテーションの決まり、フットサルのルール、データの控え |

## ファイル構成

```
index.html
public/            アイコン、manifest.webmanifest、sw.js（オフライン用）
src/
  main.jsx         起動
  App.jsx          タブの切り替えと全体の枠
  styles.css       見た目（色は先頭の変数で一括管理）
  ui.jsx           共通の小さな部品（ステッパー、シートなど）
  lib/
    rotation.js    ローテーションの計算（画面に依存しない）
    store.js       データの形・変更ルール・保存
    util.js        日付や共有、タイマー音など
  screens/         画面ごとのファイル（Setup / Match / Table / Records / More）
tests/
  rotation.test.mjs  計算のテスト
```

## 動かし方

```
npm install
npm run dev      # 開発用サーバー
npm test         # ローテーション計算のテスト
npm run build    # 本番用ビルド（dist/）
```

## デプロイ（Vercel）

これまでと同じ設定のまま使えます（Framework Preset: Vite ／ Root Directory: `futsal-app`）。
GitHub の `futsal-app/` フォルダの中身をこのフォルダの中身で置き換えて commit すると、自動でデプロイされます。
`node_modules` と `dist` はアップロード不要です。

## ローテーションの決まり

1. コートは必ず5人（GK1＋フィールド4）。6人以上なら残り全員が休み
2. 休みの次にGKはなし／GKの次に休みはなし（絶対ルール）
3. GK回数・休み回数はなるべくそろえ、連続の休みはなるべく出さない
4. 遅れて来た人は着いた試合から。着いた直後のGKは避ける
5. 5人に足りない試合は助っ人で補う（1人目の助っ人がGK）。2人未満は「メンバー待ち」

計算は `src/lib/rotation.js` の `planRotation`。下書き（1試合ずつ順に組む）→ 清書（入れ替えを繰り返して偏りを減らす）の2段階です。
